# Research-only quantized MEAN integration

The pretrained graphs and frozen MNIST contain no MEAN nodes. Their standard app uses the pinned TFLite Micro registration. For the custom stage all four local apps share the exact same adapter source and runtime registration; only ESP-NN differs. Unsupported operations use the original TFLite Micro registration. The pinned runtime also has its own contiguous INT8 MEAN optimization, which remains within TFLite Micro.

The guarded match requires batch-one four-dimensional NHWC INT8, per-tensor affine quantization, retained dimensions and an exact spatial reduction of axes 1 and 2. It verifies matching output shape, 16-byte alignment on both tensors, disjoint byte ranges, positive dimensions and spatial area at most 4,095. The quantization mapping is enabled only for the stock double-rounding operation with effective shift between −30 and 0.

With area A, TFLite Micro starts from its Q31 multiplier m and shift s for the input/output scale ratio. It rescales the already quantized multiplier with k = min(floor(log2(A)), 32, 31+s), m' = floor((m × 2^k)/A) and s' = s−k. ESP-NN receives m' and s'. Both subtract the input zero point times A from the channel sum, apply double rounding, add the output zero point and clamp to INT8. The restricted range avoids overflow or an unsupported signed shift. The QACC candidate separately checks the 16-channel and 20-bit lane accumulation limits.

The stress build checks the shared mapping and actual kernel output against TFLite Micro's exact QuantizedMeanOrSum implementation for thousands of complete tensors per firmware across the specified shapes, shifts, ratios, zero points, and deterministic random and adversarial inputs. The per-model untimed probe also checks the actual layer input against both the generic and pinned registered TFLite Micro evaluation paths and records the QACC helper calls. The timed firmware excludes the reference double-evaluation and all linker wraps.
