# Experimental TFLite Micro MEAN adapter

The same app-only registration is used with all four ESP-NN revisions. It retains TFLite Micro's original reduction preparation and scratch planning. Unsupported operators fall back to the original TFLite Micro registration. ESP-TFLite Micro v1.4.3 already has a contiguous INT8 MEAN path in its ESP-NN kernel directory, which does the reduction within TFLite Micro. It does not call ESP-NN's global-mean API.

The adapter accepts batch-one rank-four NHWC INT8 tensors with per-tensor affine quantization, spatial axes 1 and 2 in either order, retained spatial dimensions, the matching output shape, a spatial area from 1 to 4,095, and nonoverlapping, 16-byte-aligned input and output buffers. The rounding and shift checks require the common double-rounding mode and an effective shift from −30 to 0. EXP-MEAN adds its own QACC eligibility gate, including channels divisible by 16.

For spatial area A, the pinned TFLM implementation obtains a Q31 multiplier m and exponent s from the input/output scale ratio. It computes k = min(floor(log2(A)), 32, 31 + s), then gives its multiplier routine floor((m × 2^k)/A) and exponent s − k. The adapter reproduces that integer division. Calling the scale quantizer again on the floating-point ratio divided by A could change rounding. ESP-NN sums signed INT8 values, subtracts A × input zero point, applies the same two rounding stages, adds the output zero point and clamps to INT8. With a nonpositive effective shift and the area bound, the corrected sum is within ±1,044,225.

The diagnostic evaluates the generic TFLM reference, the original ESP-TFLM registration, and ESP-NN on the actual intermediate tensor and five deterministic patterns. Patterns include both INT8 extremes, the input zero point, alternating extrema, and a signed ramp. It restores the intermediate input and invokes ESP-NN again before the model continues. QACC probe counts include these validation calls. It returns an error on any inequality. The production-shaped timed firmware excludes this probe and contains a single selected MEAN route per invocation.

The kit's Dense lowering also needs INT32 shape-vector GATHER and REDUCE_PROD, which the pinned TFLite Micro cannot resolve for these inputs. The experiment implements those narrow reference shape operations in the app for every firmware. Model graphs and weights are unchanged.
